## Lógica del juego

Juego tipo *crash*: un cohete despega y el multiplicador crece hasta que explota en un punto aleatorio. El jugador debe retirar antes de la explosión.

- **Ciclo de rondas:** en `onMounted()` un `setInterval` de 100 ms gestiona los estados `gameState`:

  ```mermaid
  stateDiagram-v2
      [*] --> waiting
      waiting --> starting: el jugador apuesta (hasPlacedBet)
      starting --> running: countdown llega a 0 (5 s) → startGame()
      running --> crashed: multiplicador ≥ crashPoint → endGame()
      crashed --> waiting: resetForNextRound()
  ```

- **Punto de explosión — `startGame()`:**

  ```js
  crashPoint = crashSeed.value !== null
    ? crashSeed.value
    : 1 + Math.pow(Math.random(), 4) * 20; // entre 1x y 21x, sesgado a valores bajos
  ```

  `crashSeed` es una variable de desarrollo para forzar el punto de explosión en pruebas (`null` = aleatorio).
- **Multiplicador — `gameLoop()`:** `currentMultiplier = 1.07 ^ segundos_transcurridos`. Se dibuja el cohete, su estela y un campo de 100 estrellas en `<canvas>` (800 × 450) con `draw()`; los hitos ×2, ×5 y ×10 producen un efecto de pulso.
- **Historial:** `endGame()` agrega cada `crashPoint` a `history` (máximo 20 entradas), coloreado por `getHistoryClass()`.

## Apuestas

| Control | Valor |
|---------|-------|
| Apuesta | `betAmount` (10 por defecto), entre 1 y 1000; `increaseBet()` / `decreaseBet()` en pasos de `betStep = 5`; `setMaxBet()` = `min(1000, credits)`; `setBet(amount)` para valores rápidos |
| Auto-retiro | `autoCashout` (opcional): si el multiplicador alcanza este valor, se ejecuta `cashOut(autoCashout)` automáticamente |
| Botón principal — `handleAction()` | En `waiting`/`starting`: marca `hasPlacedBet` (la apuesta se registra al final). En `running`: retira con el multiplicador actual |

## Registro del resultado

Retiro, en `cashOut(multiplier)`:

```js
const winnings = betAmount.value * multiplier;
await registerBet({
  uid: uid.value,
  gameId: GAME_IDS.ROCKET,
  amount: betAmount.value,
  result: 'GANADA',
  multiplier: multiplier,
  netWin: winnings - betAmount.value
});
await syncBalance();
```

Explosión sin haber retirado, en `endGame()`:

```js
await registerBet({
  uid: uid.value,
  gameId: GAME_IDS.ROCKET,
  amount: betAmount.value,
  result: 'PERDIDA',
  multiplier: 0,
  netWin: -betAmount.value
});
await syncBalance();
```

## Lógica del juego

- Máquina de **3 carretes** con los símbolos `🍒 🍊 🍋 🍇 ⭐ 💎 🔔 7️⃣` (`symbols`).
- **Giro — `spin()`:** requiere `credits >= currentBet`. Elige al azar los tres símbolos finales (`targetSymbols`), rellena cada carrete con 20 símbolos aleatorios para la animación y arranca `animateReels()`.
- **Animación:** dibujada en `<canvas>` (`drawSlotMachine()`, `drawSymbol()`). Duración `spinDuration = 4000` ms; los carretes se detienen escalonadamente al 60 %, 75 % y 90 % del tiempo, con velocidades distintas y easing de desaceleración. Al terminar, `reels` toma el valor de `targetSymbols` y se llama a `checkWin()`.

## Apuestas

| Regla | Valor |
|-------|-------|
| Apuesta inicial | `currentBet = 10` |
| Mínimo / máximo | `minBet = 5` / `maxBet = 100` |
| Incremento | `betStep = 5` (`increaseBet()` / `decreaseBet()`) |
| Apuesta máxima | `setMaxBet()` → `min(credits, maxBet)` |

### Tabla de pagos (`paytable`)

| Combinación | Multiplicador |
|-------------|---------------|
| 🍒 🍒 🍒 | 10 |
| 🍊 🍊 🍊 | 15 |
| 🍋 🍋 🍋 | 20 |
| 🍇 🍇 🍇 | 25 |
| ⭐ ⭐ ⭐ | 50 |
| 💎 💎 💎 | 100 |
| 🔔 🔔 🔔 | 200 |
| 7️⃣ 7️⃣ 7️⃣ | 777 |
| Cualquier par (dos símbolos iguales) | 0.5 |

> En el código actual, las claves de `paytable` para las cerezas y las naranjas no coinciden exactamente con `reels.join(' ')` (la primera contiene un carácter dañado y la segunda tiene solo dos naranjas y un espacio final). En la práctica, tres cerezas o tres naranjas se pagan como "par" (×0.5).

## Registro del resultado

`checkWin()` busca la combinación en `paytable`; si no existe, comprueba si hay al menos dos símbolos iguales:

```js
let resultado = 'PERDIDA';
let multiplicador = 0;
// combinación de tres → resultado = 'GANADO', multiplicador = payout
// par              → resultado = 'GANADO', multiplicador = 0.5

const netWin = resultado === 'GANADA' ? this.lastWin - this.currentBet : -this.currentBet;

await registerBet({
  uid: this.uid,
  gameId: GAME_IDS.SLOTS,
  amount: this.currentBet,
  result: resultado,
  multiplier: multiplicador,
  netWin: netWin
});
await syncBalance();
```

> **Inconsistencia conocida:** las victorias se marcan como `'GANADO'`, pero el cálculo de `netWin` compara con `'GANADA'`, por lo que `netWin` siempre vale `-currentBet`. Como el backend ignora `p_ganancia_neta`, el efecto práctico depende de cómo `usp_apuesta_crear` interprete `p_resultado = 'GANADO'` y `p_multiplicador`.

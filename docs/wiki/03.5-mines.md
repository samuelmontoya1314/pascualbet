# 3.5 Mines

Componente: `front/src/components/games/mines.vue` · Ruta: `/mines` · `GAME_IDS.MINES` = 5

[← Juegos](03-juegos.md)

## Lógica del juego

- Cuadrícula configurable de **3×3 a 9×9** (`gridDimension`, 5×5 por defecto) con un número de minas entre 1 y `GRID_SIZE - 1` (`numMines`, 3 por defecto). Al cambiar el tamaño, `numMines` se ajusta si supera el máximo.
- **Inicio — `startGame()`:** crea la cuadrícula con `initializeGrid()` y coloca las minas en posiciones aleatorias únicas. Estado: `betting` → `playing`.
- **Revelar — `onTileClick(index)`:**
  - Mina → estado `busted`, se revelan todas las minas (`revealAllMines()`) y se registra la pérdida.
  - Diamante → incrementa `diamondsFound`. Si solo había una casilla segura (`numMines === maxMines`) se cobra automáticamente.
- **Multiplicador:** `currentMultiplier` se lee de `MULTIPLIER_TABLE[numMines][diamondsFound - 1]` (1.0 si no hay diamantes o no existe la entrada). La tabla define multiplicadores para 1–24 minas; por ejemplo, con 3 minas: 1.12, 1.29, 1.48, 1.71, 2.00, … Está pensada para una cuadrícula de 25 casillas (5×5); en otros tamaños se usa la misma tabla.
- **Cobrar — `cashout()`:** disponible en estado `playing` con al menos un diamante. Muestra la ganancia neta en `lastWinnings`.
- `resetGame()` vuelve al estado `betting` para otra partida.

## Apuestas

- `betAmount` (10 por defecto) debe ser mayor que 0 y no superar `credits` (`isBetInvalid`).
- La apuesta no se descuenta al iniciar; se registra al terminar la partida (mina o cobro).

## Registro del resultado

Pérdida, en `onTileClick()` al pisar una mina:

```js
await registerBet({
  uid: uid.value,
  gameId: GAME_IDS.MINES,
  amount: betAmount.value,
  result: 'PERDIDA',
  multiplier: 0,
  netWin: -betAmount.value
});
await syncBalance();
```

Ganancia, en `cashout()`:

```js
const winnings = betAmount.value * currentMultiplier.value;
await registerBet({
  uid: uid.value,
  gameId: GAME_IDS.MINES,
  amount: betAmount.value,
  result: 'GANADA',
  multiplier: currentMultiplier.value,
  netWin: winnings - betAmount.value
});
await syncBalance();
```

## Sonido

Tone.js: `PolySynth` (acorde) al encontrar diamante, `MembraneSynth` para la explosión, `MonoSynth` para la derrota y `PolySynth` para el cobro.

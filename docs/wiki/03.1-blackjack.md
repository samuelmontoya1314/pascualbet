# 3.1 Blackjack

Componente: `front/src/components/games/Blackjack.vue` · Ruta: `/BJ` · `GAME_IDS.BLACKJACK` = 3

[← Juegos](03-juegos.md)

## Lógica del juego

- **Baraja:** `createDeck()` genera 52 cartas (palos `♠ ♥ ♦ ♣`, rangos 2–10, J, Q, K, A). `shuffleDeck()` la mezcla con el algoritmo Fisher–Yates y `drawCard()` saca cartas con `pop()`. Se crea una baraja nueva en cada mano.
- **Puntuación:** `calculateScore(cards)` cuenta figuras como 10 y ases como 11; mientras la suma pase de 21 y queden ases, resta 10 por cada as (as flexible 1/11). `playerScore` y `dealerScore` son propiedades computadas.
- **Inicio — `startGame()`:** reparte dos cartas al jugador y dos al crupier. Si el jugador tiene 21 de inicio:
  - y el crupier también → empate (`'EMPATE'`, multiplicador 1);
  - si no → **Blackjack** (`'GANADO'`, multiplicador 2.5, es decir, pago 3:2).
- **Pedir — `hit()`:** agrega una carta. Si el jugador pasa de 21 pierde (`'PERDIDO'`, 0); si llega exactamente a 21 se planta automáticamente.
- **Plantarse — `stand()`:** el crupier pide cartas mientras tenga menos de 17. Luego:
  - crupier > 21 o jugador > crupier → victoria (`'GANADO'`, 2);
  - jugador < crupier → derrota (`'PERDIDO'`, 0);
  - igualdad → empate (`'EMPATE'`, 1).
- Incluye un modal de ayuda con las reglas (`openHelpModal()` / `closeHelpModal()`).

## Apuestas

| Regla | Implementación |
|-------|----------------|
| Mínimo | 10 (`startGame()` muestra un `alert` si `betAmount < 10`) |
| Máximo | 500 (`validateBetAmount()` limita el valor) |
| Saldo | `betAmount` no puede superar `credits` |
| Controles | `increaseBet()` / `decreaseBet()` en pasos de 10; `setBetAmount(amount)` para valores rápidos |

## Registro del resultado

Todas las salidas convergen en `endGame(message, resultado, multiplicador)`:

```js
const netWin = this.betAmount * multiplicador - this.betAmount;

await registerBet({
  uid: this.uid,
  gameId: GAME_IDS.BLACKJACK,
  amount: this.betAmount,
  result: resultado === 'EMPATE' ? 'GANADA' : resultado,
  multiplier: multiplicador,
  netWin: netWin
});
await syncBalance();
```

| Desenlace | `result` enviado | `multiplier` | `netWin` |
|-----------|------------------|--------------|----------|
| Blackjack natural | `'GANADO'` | 2.5 | `+1.5 × apuesta` |
| Victoria normal | `'GANADO'` | 2 | `+apuesta` |
| Empate | `'GANADA'` | 1 | 0 |
| Derrota / pasarse | `'PERDIDO'` | 0 | `-apuesta` |

> Blackjack usa `'GANADO'` / `'PERDIDO'` (masculino), a diferencia de los juegos que usan `'GANADA'` / `'PERDIDA'`. El empate se registra como `'GANADA'` con multiplicador 1 para que se devuelva la apuesta.

## Sonido

Usa Tone.js (importado dinámicamente con `import('tone')` y guardado en `window.Tone`): `NoiseSynth` con filtro paso alto para las cartas, `PolySynth` para ganar/perder (acorde mayor/menor) y `FMSynth` para el empate.
